# @linked.cm/profile

Reusable profile Shapes, profile-picture UI contracts, and authenticated backend operations for Linked applications.

This package is currently at `0.1.x`. Its UI and backend entry points are contract stubs until the profile extraction is completed.

The package deliberately preserves the existing `http://lincd.org/ont/profile-pics/` and selected `http://lincd.org/ont/profile-plus/` RDF terms so existing application data remains readable.
